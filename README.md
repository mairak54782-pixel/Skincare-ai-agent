# 🌸 BellaAI — Smart Skincare Assistant

Most skincare apps assume you have access to Western brands and a dermatologist on speed dial. BellaAI doesn't — it's built around what's actually available here: local brands like Jenpharm, Primary and Vince, and advice that accounts for Pakistan's heat, humidity, and dust rather than ignoring it.

It's a Streamlit app powered by an LLM (via Groq) that gives you a personalized AM/PM routine, lets you describe your skin and get a quick read on what's going on, and answers general skincare questions — all in plain, no-jargon language.

## What it does

**Routine Generator** — pick your skin type, the current season, your age, and what's bothering you (acne, dark spots, dryness, etc.), and get a morning + night routine with an actual reason behind each step, not just a product list.

**Skin Analysis** — describe how your skin behaves in your own words ("gets oily by 2pm but feels tight after washing") and get back a few specific, practical tips instead of a generic checklist.

**Skincare Chat** — a running conversation for one-off questions: what an ingredient does, whether two products can be used together, whether something is worth buying.

**PDF export** — turn a generated routine into a PDF you can actually save and refer back to, instead of losing it in a chat history.

## Why I built it this way

The first version called the model directly from inside `app.py`, which got messy fast — prompt strings tangled up with UI code, hard to tweak one without breaking the other. I split it into `app.py` (just the Streamlit UI) and `utils/ai_engine.py` (prompt building, the API call, PDF generation), so each piece can be changed independently. It's a small app, but structuring it this way made debugging and iterating on prompt wording much easier.

## Tech stack

| Layer | Choice | Why |
|---|---|---|
| UI | Streamlit | Fast to build, good enough for a focused single-purpose app |
| Inference | Groq API (`openai/gpt-oss-20b`) | Free tier, very low latency compared to most hosted APIs |
| PDF export | ReportLab | Lightweight, no external service needed |
| Config | python-dotenv | Keeps the API key out of the codebase |

## Running it locally

```bash
git clone https://github.com/mairak54782-pixel/Skincare-ai-agent.git
cd Skincare-ai-agent

python -m venv venv
venv\Scripts\activate        # macOS/Linux: source venv/bin/activate

pip install -r requirements.txt
```

Copy `.env.example` to `.env` and add a [Groq API key](https://console.groq.com/keys) (free to get):
```
GROQ_API_KEY=your_actual_key_here
```

Then run:
```bash
streamlit run app.py
```

## Deploying

Deployed on [Streamlit Community Cloud](https://streamlit.io/cloud), which is free for public repos:

1. Push the repo to GitHub.
2. Connect it at [share.streamlit.io](https://share.streamlit.io).
3. Under **App settings → Secrets**, add `GROQ_API_KEY = "your_key"`.
4. Deploy — you'll get a public `.streamlit.app` URL.
